## Agent skills

### Issue tracker

Issues are tracked in this repo's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `CONTEXT.md` at the repo root, plus `docs/adr/` for architecture decisions. See `docs/agents/domain.md`.

## Code standards

Rust code follows `docs/agents/code-standards-rust.md`, which records the lint set, the error type for each crate, and the testing rules. Before writing, reviewing or refactoring any Rust, load the `ms-rust` skill: its `SKILL.md` names the guideline files to read for the task at hand.
