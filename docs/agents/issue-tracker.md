# Issue Tracker

Issues for this repo are tracked in **GitHub Issues**.

Skills like `to-tickets`, `to-spec`, and issue-related commands read from and write to issues here using the `gh` CLI.

## Workflow

- Create issues: `gh issue create`
- Read issues: `gh issue list`, `gh issue view <number>`
- Update issues: `gh issue edit <number>`

## PRs as request surface

External PRs as feature requests are **disabled** (not added to the issue queue by default). Uncomment the flag in this file if you want to enable it later.
