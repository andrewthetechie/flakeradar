# Domain Docs

This repo uses a **single-context** layout:

- **`CONTEXT.md`** at the repo root: shared domain language and concepts
- **`docs/adr/`**: Architecture Decision Records

## Consumer rules

When reading domain context:
1. Always start with `CONTEXT.md` for terminology and mental models
2. Check `docs/adr/` for decisions that shaped the architecture
3. Use these to ground all technical work in the project's language

Skills automatically read both files when context is needed.
